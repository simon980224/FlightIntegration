# LINE Bot 新功能說明

## 📋 功能清單

### 1. ✈️ 智能登機提醒（明天起飛）

**功能描述**：
- 系統每天自動推播**明天起飛**的航班提醒
- 包含航班資訊和目的地天氣預報
- 無需用戶手動設定，訂票後自動啟用

**實作檔案**：
- `cron/amadeus_daily.py` - 整合在每日 Amadeus Cron Job 中
- 使用現有的 Windows 排程，無需額外設定

**執行方式**：
- 自動執行（已整合在 `amadeus_daily.py` 中）
- 每天執行時會自動推播明天起飛的航班

**資料來源**：
- SQL Server 資料庫（Wallet + Ticket + Flight 表）
- 查詢已付款且已綁定 LINE 的用戶訂票

---

### 2. 🎒 訂票成功推播旅遊錦囊

**功能描述**：
- 用戶訂票成功後自動推播目的地旅遊資訊
- 整合三個 API：
  - Open-Meteo：7 天天氣預報（分早晚溫度）
  - Wikipedia：必訪景點 Top 3
  - Overpass：美食推薦（含營業時間）

**實作檔案**：
- `api/linebot/travel_kit.py` - 旅遊錦囊模組
- `service/linebot_service.py` - 訂票成功後觸發推播

**觸發時機**：
- LIFF 訂票成功後自動推播
- 無需用戶額外操作

---

### 3. 📤 快速分享行程

**功能描述**：
- 在「查看訂票」卡片中新增「分享行程」按鈕
- 點擊後生成包含航班、天氣、景點的精美卡片
- 可直接轉發給 LINE 好友

**實作檔案**：
- `api/linebot/share_itinerary.py` - 分享行程模組
- `api/linebot/richmenu_flow.py` - 處理分享 Postback

**使用方式**：
1. 用戶輸入「查看訂票」
2. 點擊「分享行程」按鈕
3. 系統生成可分享的 Flex Message
4. 用戶可轉發給好友

---

### 4. 🌤️ 多日天氣預報（分早晚）

**功能描述**：
- 提供 7 天天氣預報
- 顯示每日最低/最高溫度
- 顯示降雨機率
- 使用天氣代碼轉換為 emoji

**實作檔案**：
- `api/linebot/travel_kit.py` - 天氣預報功能

**API 使用**：
- Open-Meteo API（免費）
- 參數：`daily=temperature_2m_max,temperature_2m_min,precipitation_probability_max,weather_code`

---

## 🎨 設計原則

### 簡潔實用
- 使用適量 emoji，不過度裝飾
- 資訊清晰易讀
- 避免過多文字

### 技術整合
- 整合 Open-Meteo、Wikipedia、Overpass 三個免費 API
- 展示 LINE Bot 的獨特價值（推播、情境化服務）

### 用戶體驗
- 主動推播，無需用戶手動查詢
- 零摩擦互動，一鍵分享
- 提供實用資訊（天氣、景點、美食）

## 🧪 測試步驟

### 測試 1：智能登機提醒
1. 在資料庫新增一筆**明天**起飛的航班訂票
2. 執行 `python cron/amadeus_daily.py`
3. 檢查 LINE Bot 是否推播提醒訊息（會在 Amadeus 查詢完成後執行）

### 測試 2：訂票成功推播
1. 在 LINE Bot 查詢航班
2. 點擊「立即訂票」完成訂票
3. 檢查是否收到旅遊錦囊推播

### 測試 3：快速分享行程
1. 輸入「查看訂票」
2. 點擊「分享行程」按鈕
3. 檢查是否生成可分享的卡片

## 📝 注意事項

1. **資料庫需求**：
   - User 表需要 `User_LineId` 欄位（已存在）
   - Wallet 表需要 `Status` 欄位（已存在）

2. **API 限制**：
   - Open-Meteo：免費，無需 API Key
   - Wikipedia：免費，無需 API Key
   - Overpass：免費，但有請求頻率限制（建議加快取）

3. **排程設定**：
   - 登機提醒已整合在 `amadeus_daily.py` 中，無需額外設定
   - 使用現有的每日排程即可

4. **錯誤處理**：
   - 所有 API 呼叫都有 try-except 保護
   - API 失敗時顯示「資訊暫時無法取得」
   - 不影響主要訂票流程
